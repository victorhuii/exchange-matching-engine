Durability and limits

Acknowledgments follow a checksummed journal append and fsync. An unacknowledged command may still be recovered. Retry the same request ID and command to avoid duplication. Snapshot recovery compares the full book, trades and balances.

One writer owns the data directory. The workbench caps at 5,000 accepted commands; the CLI core caps at 100,000. Journal, request responses and trades remain in full. This is an inspectable simulator, not a production exchange.
